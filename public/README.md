# BuildHer Bharat 2026 — Premium Animated Website

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Install the Live Server extension (or use any static HTTP server).
4. Open `index.html` with Live Server.

- Premium dark futuristic visual style based on the Aarambhathon reference
- Responsive layout and supplied BuildHer Bharat / institutional partner logos
- Official Unstop registration URL and supplied 400×400 QR image

## Important
Registration is completed on Unstop. This static website does not collect participant data or process submissions itself. Organiser profile cards use initials and LinkedIn search links until approved photos and direct profile URLs are supplied.

## Site-wide animation update
